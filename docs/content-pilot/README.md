# 題庫風格與四語試作：第一批

此批是供檢閱的內容草稿，未匯入正式資料庫。`prompts.json` 包含 3 題既有大冒險的忠實翻譯，以及 8 題依其寫法延伸的非露骨互動題，共 11 題、44 段語系文字。骰子項目是完整任務原型，不能直接塞進現有動作或部位骰面。

## 風格依據

2026-09-07 讀取的資料庫大冒險 ID 19、20、22：

- 短句，直接告訴玩家做什麼。
- 清楚指定參與者和持續時間。
- 以耳語、眼神、擁抱等具體互動營造親密感。
- 任務可以有勝負、輪替或選擇，應配合各遊戲規則。

資料庫沒有作者標記，因此這些 ID 是風格參考來源，不是作者身分證明。本批沒有更改原作文字或原有分級；新增題目的強度只是待審建議。

## 檢閱方式

先檢查繁中版本的語氣是否符合品牌，再對照其他語系。`existing_translation` 是原題翻譯；`adaptation` 是新題草稿。`source_refs` 表示靈感來源，不代表新題是原作或忠實翻譯。所有項目都是 `draft`，尚未經母語審校。

國王遊戲的 `{A}`、`{B}` 必須原樣保留；時間、動作發起者與接受者不得互換。「誰最有可能」採片語，交由遊戲既有提問前綴銜接。實際上線時需逐語系檢查前綴、標點和題目組成後的整句。

## 第一批差異

- 撲克牌：勝者／敗者各自有角色，避免只把轉盤題目前面加上牌大牌小。
- 國王遊戲：使用編號角色及角色交換，讓兩人都有回合。
- 轉盤：單題即可執行，不依賴上一回合。
- 誰最有可能：使用可以投票的行為描述。
- 骰子：先以完整任務確認語序；現有詞片式骰面需另做組合相容性設計。
- 飛行棋：用抵達格子觸發一段短互動，不擅自引入未實作的移動獎懲。
