# 性反應雙軸量表的圖片位置

放進來就會出現,沒放就整段不渲染(見 `app/Support/helpers.php` 的 `optional_image()`)。
副檔名找的順序是 `.webp` → `.jpg` → `.png`,所以之後換成 webp 不用改程式。

| 檔名 | 出現在哪 | 建議尺寸 | 內容方向 |
|---|---|---|---|
| `cover.webp` | 題目頁 `/tw/dual-control` 標題下方 | 1600×900 (16:9) | 這份量表的封面。兩條軸的意象:興奮與抑制、想要與不敢 |
| `simmering.webp` | 高張力型結果頁 | 1600×900 (16:9) | 想要卻踩著煞車。壓著、忍著,但溫度很高 |
| `open.webp` | 開放型結果頁 | 1600×900 (16:9) | 想要就去要。放鬆、主動、燈是開著的 |
| `easy.webp` | 平緩型結果頁 | 1600×900 (16:9) | 不特別想,但一點都不彆扭。慢、自在、不焦慮 |
| `locked.webp` | 封閉型結果頁 | 1600×900 (16:9) | 關著的。距離感、遮蔽、看著自己 |
| `middle.webp` | 均衡型結果頁 | 1600×900 (16:9) | 想要,旁邊同時有一個聲音在評論 |

## 注意

- **版位是 16:9,`object-fit: cover`**,所以主體放中間,上下各留一點被裁掉的餘裕。
- 這是成人向的站,但這幾張是**公開頁面的主視覺**,而且結果頁會被搜尋引擎收錄 ——
  露點會影響索引與廣告商。方向抓「氛圍」而不是「器官」:光線、姿態、手、背影、
  布料、剪影都可以。
- 深色底的站(`--bg: #0d0f16`),暗調的圖接得比較順;過亮的圖會像貼上去的。
- 五張建議同一組風格與色調 —— 五個結果頁是互相連結的,風格跳掉會像五個不同的站。
